Plan mode

Shift+TabToggle plan mode on/off
Ctrl+GOpen the plan in your editor
Claude reads & proposes a plan; no edits until you approve. Use it when the fix isn't obvious or spans files.

Verify & review

run the testsGive Claude a check it can iterate against
/code-reviewFresh-context review of the diff
A second look in a clean context catches what the author (you or Claude) misses.

Course-correct

EscStop Claude mid-action; context kept
/rewindUndo a wrong turn (conversation/code)
Rewind makes risky fixes cheap. Try something; roll it back if it's wrong.
